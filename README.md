## 🗨️ About Turing

튜링(Turing)은 대학생 과외 선생님들을 타겟으로, 수업 전후 상황 속 불편함을 해소하는 과외 보조 서비스입니다. <br>
유저의 텍스트 입력을 적게 요구하고, 개입은 적극적인 서비스로 포지셔닝하여, 유저의 편의성 극대화를 목표로 삼았습니다.
